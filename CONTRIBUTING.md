# Guide de Contribution 🤝

Merci de l'intérêt que vous portez à **Findor Pro** ! Nous sommes ravis de recevoir votre aide.

## 🚀 Comment contribuer ?

### 1. Rapporter des bugs 🐛
Si vous trouvez un bug, veuillez ouvrir une "Issue" sur GitHub en expliquant :
- Les étapes pour reproduire le bug.
- Votre environnement (version de Linux, version de Python).
- Ce que vous attendiez par rapport à ce qui s'est réellement passé.

### 2. Proposer des fonctionnalités ✨
Les nouvelles idées sont les bienvenues ! Ouvrez une "Issue" pour en discuter avant de commencer le développement.

### 3. Soumettre des changements (Pull Requests) 🛠️
- Créez un fork du dépôt.
- Créez une branche descriptive (`feature/nom-de-la-feature` ou `fix/nom-du-bug`).
- Assurez-vous que votre code suit les standards du projet (voir `GEMINI.md`).
- Documentez vos changements.
- Ouvrez une Pull Request.

## 📝 Standards de Code
- **Langue** : Commentaires en français, code en anglais.
- **Python** : Respect de la PEP 8.
- **React** : Composants fonctionnels et TypeScript.

## 🏗️ Environnement de développement
Référez-vous au `README.md` pour les instructions d'installation du backend, du frontend et de la version desktop.

Merci pour votre aide !
